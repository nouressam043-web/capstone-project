# Capstone Project

This repository is for my AI-assisted development capstone project.

## Overview
The project demonstrates using Node.js, Git, and AI tools (Claude Code / Cursor) to assist development.

## Project Goals
This capstone project explores how AI-assisted tools can improve software development workflows. The goal is to demonstrate effective use of Node.js, Git, and AI coding assistants such as Claude Code and Cursor for planning, implementation, and project organization.

Key goals:
- Use AI tools to accelerate development while maintaining code quality
- Practice modern workflow conventions and version control
- Build a clean, maintainable project structure
- Document the process clearly for review and future collaboration

## Installation
- Install Node.js (LTS)
- Install Git
- Clone this repository

## Usage
Open the project in Cursor or Claude Code and follow the conventions in CLAUDE.md.
